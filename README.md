PASOS DE EJECUCIÓN
1.	Descargar el repositorio localmente utilizando.
2.	Abrir el entorno de desarrollo Apache NetBeans.
3.	Ir a File > Open Project y seleccionar la carpeta descargada PuntoDeVentaJASE.
4.	Hacer clic derecho sobre el proyecto en la pestaña Projects y seleccionar Clean and Build para compilar el código y generar el directorio target/classes.
5.	Ejecutar la clase principal (App.java) haciendo clic derecho y seleccionando Run File.
6.	Al iniciar por primera vez, el sistema creará automáticamente el archivo punto_venta.db..
7.	Ingresar al sistema con las credenciales de Administrador para acceder a los módulos de Inventario, Reportes y Recargas.
